# 03 — Core Azure Services

## Compute

- **Virtual Machines** — IaaS, full control
- **VM Scale Sets** — autoscaling group of identical VMs
- **App Service** — PaaS for web apps
- **Container Instances (ACI)** — single container, serverless
- **Container Apps** — serverless containers with KEDA scaling
- **AKS** — managed Kubernetes
- **Functions** — serverless event-driven compute

## Networking

- **Virtual Network (VNet)** — isolated network in Azure
- **Subnet** — subdivision of a VNet
- **VNet peering** — connect VNets
- **VPN Gateway** — site-to-site, point-to-site, VNet-to-VNet
- **ExpressRoute** — private dedicated connection
- **Load Balancer** — L4 distribution
- **Application Gateway** — L7 distribution + WAF
- **Azure DNS** — managed DNS hosting

## Storage

- **Storage Account** — wrapper for blob, file, queue, table
- **Blob Storage** — object storage (S3 equivalent)
- **Azure Files** — managed SMB/NFS shares
- **Disk Storage** — managed disks for VMs

## Databases

- **Azure SQL Database** — PaaS SQL Server
- **Azure SQL Managed Instance** — near-100% SQL Server compat
- **Cosmos DB** — multi-model NoSQL
- **Azure Database for MySQL / PostgreSQL** — managed open source
